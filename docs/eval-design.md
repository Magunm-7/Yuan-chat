## 0. 一句话

在 AnnoMI 上，用弱监督训一个**序列状态估计器**，产出每段会话的**状态轨迹**；
用专家标签 `client_talk_type` / `mi_quality` 验证：轨迹能否还原来访者状态、其**形状**能否区分咨询质量、其**不确定性 σ** 是否可信。
**不声称临床有效性，不做抑郁检测，不做逐句因果归因（数据不支持）。**

---

## 0.5 为什么是这个架构：数据 → 决定

搭模型前先在 gold label 里跑了 premise 测试（`notes.md` §6.8），四个发现定了架构：

| 数据发现 | 架构决定 |
|---|---|
| F1 逐句归因空（reflection 对下一句净效应 −0.002） | 砍掉转移头 + 动作条件 |
| F2 会话弧线真实（改变倾向 50%→82%） | 保留 GRU，职责=出轨迹 |
| F3 形状分质量（high 单调 53→68→84，low 中段塌 48→26→80） | 读出层瞄准轨迹形状 |
| F4 动作预测力≈0（Spearman 0.07） | 咨询师动作降为协变量 |
| F5 neutral 占 64%、逐句噪声大 | 序列模型去噪 |

**最终架构**：`序列估计器(GRU) → 逐句 μ + σ → 会话轨迹 → 读形状`。
比原 v1-强更简单：无转移头、无动作条件。这不是退步，是数据否掉了那两个零件。

## 1. 指标维度（构念错配已解决）

原 MVP 的 dep/sad/anx/stress 在 AnnoMI（戒酒戒烟场景）上大概率近乎常数，会重演"信号太弱"。重构为：

| 维度 | 含义 | 模态归宿 | 外部验证 |
|---|---|---|---|
| **chg** | 改变倾向（change-orientation） | 文本主导 | ✅ `client_talk_type` |
| **val** | 情绪效价（负↔正） | 视频+音频 | 无（辅助） |
| **aro** | 唤起/紧张度 | 音频主导 | 无（辅助） |
| eng（可选） | 投入/敞开度 | 视频+韵律 | 无（辅助） |

- `val + aro` = 经典情感二维（Russell circumplex），天然多模态，可引用。
- `chg` 是唯一带外部真值的维度，命题验证全靠它。
- `microexpr_rate` **降级**为输入特征/质量项，不再占 μ 的输出头。

**⚠️ 最终维度由方差探针定，不靠拍脑袋**（见 §5 步骤 2）。近乎常数的维度 = 该数据上无测量价值，砍掉。
探针无需大 LLM：chg 直接用 AnnoMI 标签（免费）、aro 用音频韵律（CPU）、val/eng 用小情感模型（CPU）。

## 3. 锁定的三个假设

### H1（估计器有效性）：μ_chg 能逐句还原 talk_type

- talk_type 序数：change=−1, neutral=0, sustain=+1（与 μ 同向，越低越"改变"）
- **主指标**：Spearman ρ(μ_chg_t, talk_type_t)，session 内算后合并
- **副指标**：AUC(μ_chg → 判别 change vs sustain，丢 neutral)
- **baseline B2**：小情感模型/VADER 直接预测 talk_type。**MPSE 打不过它就白搭**
- 判定：ρ 显著为正且 AUC > 0.60

### H2（轨迹形状）：形状特征区分 MI 质量

- 每段会话把 μ_chg 序列拟成轨迹，抽形状特征：
  **单调性**（Spearman(位置, μ_chg)）、**中段回撤**（mid − (early+late)/2）、**平滑度**（相邻二阶差分方差）、净漂移（late − early）
- **指标**：这些特征 → `mi_quality` 的 AUC，133 段，bootstrap 95% CI
- premise 预期：**单调性/平滑度**比净漂移更能分（net 改善不分高低）
- ⚠️ low 仅 23 段，CI 会宽，**必报 CI**

### H3（σ 双重角色）

**(a) 非循环校准**（绕开 6.5-A1 的循环论证）：
- 把 client turn 按 σ̄ 分 5 个等频箱，每箱**内**算 H1 的 AUC
- 判定：AUC 随 σ 单调下降 → σ 携带"可不可信"信息。报 Spearman(箱序, 箱内 AUC)
- **这张图是全项目最重要的一张**

**(b) σ 作质量信号**（premise F3 的推论）：
- 低质量（形状震荡）会话的**会话级平均 σ 应更高**
- 指标：session-mean σ → mi_quality 的 AUC

## 4. 模型架构（锁定）

### 评估器 MPSE（主角）
- **序列**：fc 之后接 **GRU**，按 session 组 batch，μ_t 依赖历史 → 出平滑轨迹（premise F2/F3/F5 要求）
- **真多模态输入**（缺口一）：不再只喂"文本 emb + 4 标量"，直接吃 Whisper/CLIP 的**序列**表征，经 cross-attention 投影（不是 pooled，修 6.5-A8；用户复现过 LQ-Former，对口）
- 三头不变：μ(sigmoid) / logvar → σ / α(sigmoid **门控**，非 softmax，三维全用，修 6.5-A7)
- 损失：质量加权异方差 NLL + α 正则
- **编码器与生成器共享**

### 生成器（demo，非重心）
- 基模走**中间路**：文本 LLM + cross-attention 投影器注入音视频前缀（不上原生 VLM，保住项目归属、不炸 scope）
- 冻结基座 + LoRA
- **模型选型策略**：迭代期用当前中等开源模型（现代架构即可）；方法定稿后再用 H800 跑一版更大基模做最终展示。别在探索期烧大模型
- 算力：H800 可用，不是瓶颈；具体开源模型清单待架构就绪后联网拉取比对
